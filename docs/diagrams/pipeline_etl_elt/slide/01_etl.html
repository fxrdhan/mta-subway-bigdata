Dari mana data berasal?
SODA API (ridership), 8 feed GTFS-RT tiap 30 detik, dan GTFS statis.
Bagaimana dikumpulkan?
Batch: job harian inkremental (fingerprint). Stream: producer polling 30 detik ke Kafka.
Kapan ditransformasi?
Sebelum disimpan: DuckDB di staging (batch), Spark sebelum PostgreSQL (stream).
Di mana disimpan?
PostgreSQL (agregat) dan MongoDB (kedatangan, alert); data mentah tidak disimpan.
Bagaimana digunakan?
Streamlit (dashboard dan prediksi), Grafana (pemantauan), notebook ML.
